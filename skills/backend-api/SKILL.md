# Backend API Skill

Use for FastAPI endpoint changes.

1. Read the nearest `AGENTS.md` and relevant schemas, service, model, and router.
2. Preserve organization scoping and role checks.
3. Add or update Pydantic schemas and focused tests.
4. Add an Alembic migration for schema changes.
5. Run the focused pytest selection, then the full backend suite.

Do not place business logic directly in route functions.
