# Frontend Workflow Skill

Use for Next.js route and workflow changes.

1. Read `frontend/AGENTS.md` and the relevant component/API client.
2. Keep dashboard, documents, upload, settings, and drafting routes separate.
3. Keep API calls in `src/lib/api.ts` and represent loading, empty, error, and success states.
4. Run `npm run lint` and `npm run build`.
5. Do not add visual polish that hides missing authentication or error states.
